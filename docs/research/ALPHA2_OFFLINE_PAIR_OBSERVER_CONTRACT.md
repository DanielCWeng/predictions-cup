The isolated \`research/offline_pair_observer.py\` module imports **only Python stdlib**. It does **not** read network resources, import SIG/Polymarket clients, open a socket, access live account/orders, touch host/SQLite/WAL/AWS, modify LIVE MAKE, start a timer, schedule any task, write a file or enable any producer. No runtime integration or settings path exists. The default constructor cannot ingest. Even optional **offline** use requires an injected release verifier to approve a release receipt; the receipt and verifier are external obligations and **self-authentication is neither implemented nor claimed**. Tests use a visibly fabricated verifier and fabricated inputs. This is not a replacement for a signed operator research release, rights review or independent source attestation.

The proposed future source adapter should receive only already-accepted, transport-decoded **as-observed** records from current SIG \`MarketBatchDto.books\` **complete** native book with \`asOf.sequence/at\`, and from the accepted Polymarket seed-first \`OrderBookStore\` reconstructed snapshots. This PR intentionally does **not** wire those existing components or initiate new GET/POST/REST/WS calls. The as-observed claims and a local payload digest remain **unverified** until an independently permitted future producer exists. Raw source payload bytes are hashed and discarded by this module; the original issuer packets must be separately retained only in an independently authorised private custody process. JSON metadata digest alone is **not** proof of native issuer signing, clock authority, non-loss or completeness.

Strictly downstream \`screen\` emits **reference-price-only hypothetical values**, not an executable at-arrival book or fill/fee/settlement.
* One-second realtime batching does **not** prove 250ms or 1s native resting liquidity, order IDs, exact queue or cancellation. Canonical JSON-lines journal is SHA256-chain-linked and returned as bounded caller-owned bytes. No private root, token, account credentials, owner identity or raw message is stored. * Fail-closed limits: **65,536 bytes/record supplied for hashing only**, **8,388,608 bytes output total**, **20,000 records**, hard stop at 24h, no restart after any bad event, abort action irreversible.
